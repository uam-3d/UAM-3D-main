# UAM 3D

UAM3D is an asymmetrical multiplayer roguelike where one player plays against many. 

## How To Get
### From Release
1. Go to the [Latest Release](https://github.com/uam-3d/UAM-3D-main/releases/tag/week-0)
2. Download the zip
4. extract and run the .sh file
5. ???
6. Profit


### im cool and want to build from source
1. Get Godot Mono (https://godotengine.org and click on the .NET download)
2. clone the repo (git clone https://github.com/uam-3d/UAM-3D-main)
3. Open Project.godot in godot mono
4. Click on File > Export project
5. export to desired platform
